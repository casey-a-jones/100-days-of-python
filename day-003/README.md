# Day 3 - Train Game

## What I Learned
- Conditional statements with `if`, `elif`, and `else`
- Comparison operators
- Nested conditionals
- Using `.lower()` with user input
- Shorthand comparison expressions
- Multiline text and ASCII art
- Building decision-based program logic

## Project
Built a text-based Train Game where the player makes a series of choices that determine the outcome of the game.

The program checks the player's age, asks whether they want to begin, and then lets them choose between three train cars. Each choice leads to a different result.
